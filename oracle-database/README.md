### **Bước 5: Enable GitHub Pages**

1. Click tab **"Settings"** (góc phải trên)

2. Scroll xuống tìm **"Pages"** (menu bên trái)

3. Trong phần **"Build and deployment"**:
   - Source: **Deploy from a branch**
   - Branch: **main** 
   - Folder: **/ (root)**

4. Click **"Save"**

5. Đợi 1-2 phút, GitHub sẽ build

6. Refresh trang, bạn sẽ thấy link:
